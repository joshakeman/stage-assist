We are starting a portfolio application called Stage Assist.

The application compares an original theatrical script with a rehearsal
transcript and produces structured rehearsal notes. Specifically, it should produce what are 
called line notes, which point out to an actor where the lines they deliver in rehearsal
differ from the script, so that they can correct them. 

This project is also intended to demonstrate professional Claude Code usage
and prepare me for a software engineering role that uses Go on the backend
and React on the frontend.

The repository contains:

- a Go backend in /backend
- a React and TypeScript frontend in /frontend

Architecture constraints:

- Use Go for all backend and domain logic.
- Use React and TypeScript for the frontend.
- Begin with Go's standard net/http package rather than introducing a web
  framework without a demonstrated need.
- Deterministic Go code must handle parsing, normalization, alignment, and
  objective text differences.
- Claude should eventually be used only for ambiguous semantic evaluation and
  generating human-friendly rehearsal notes.
- The React application must not call Anthropic directly.
- Do not add a database, authentication, audio transcription, containers, or
  deployment during the first vertical slice.
